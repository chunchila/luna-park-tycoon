# 🎡 לונה פארק טייקון

משחק **Idle Tycoon** מלא בעברית (RTL), בקובץ HTML יחיד, מותאם למובייל ולדסקטופ.

## ▶️ שחקו עכשיו

**[https://dino-games-q3hiaedc2-romans-projects-97b8739c.vercel.app](https://dino-games-q3hiaedc2-romans-projects-97b8739c.vercel.app)**

## איך משחקים?

- 🎠 **בונים מתקנים** - קרוסלה, רכבת הרים, גלגל ענק, רכבת תופת, מכוניות מתנגשות, מגה-סלינג וקולנוע VR. כל מתקן מכניס מטבעות בכל שנייה.
- 💰 **אוספים רווחים** - כל מתקן צובר רווחים; לוחצים "אסוף" כדי לקחת את הכסף.
- ⬆️ **משדרגים** - שדרוג רמה מעלה את ההכנסה לשנייה של המתקן.
- 🤖 **שוכרים מנהלים** - מנהל אוסף את הרווחים אוטומטית, בלי לחיצות.
- 🌙 **הכנסה אופליין** - הפארק ממשיך לעבוד גם כשסוגרים את הדף (עד 12 שעות, ב-50% יעילות). בחזרה מחכה מסך "בזמן שלא היית כאן...".
- ✨ **פרסטיז'** - איפוס מלא של הפארק תמורת מכפיל קבוע של ×1.5 על כל ההכנסות. נפתח ממיליון מטבעות הרווחים מצטברים.

## טכני

- קובץ `index.html` יחיד - בלי תלות חיצונית, בלי build.
- שמירה אוטומטית מלאה ב-`localStorage` (כל 5 שניות ובעת יציאה).
- RTL מלא, כפתורים גדולים ומותאמים למגע, גרדיאנטים ואנימציות.
